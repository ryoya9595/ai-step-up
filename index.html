AI STEP-UP — 5つの実践ステップ

手を動かしながら、AIを"使える"ようになる

読むだけで終わらせない。各ステップで必ず「自分の手で1個作る」。画像から始めて、最後は自分専用のツールを作るところまで。

目次 はじめに ① 画像生成 ② 動画生成 ③ スライド作成 ④ スキル作成 ⑤ ツール作成

5ステップでステップアップ

①→⑤の順に、だんだんできることが広がっていく構成です。①〜③はAIに「作ってもらう」体験、④〜⑤は自分用の「仕組みを作る」体験。気になるステップから読んでもOK。

STEPテーマ使うAI作るもの
①画像生成ChatGPT / Gemini などSNS投稿用の画像を1枚
②動画生成Gemini / Google Flow数秒のショート動画を1本
③スライド作成ChatGPT / Gemini など提案・自己紹介スライドを1セット
④スキル作成Codex / Claude Code作業を自動化するスキルを1個
⑤ツール作成Codex / Claude Codeブラウザで動くツールを1個

無料で試せます（2026年時点）

ChatGPT / Gemini … 無料プランでOK（画像・動画生成は回数制限あり）／ Google Flow … 無料枠あり（1日のクレジット制・720p・8秒・透かし入り）／ Codex … 無料ChatGPTでも「Codex Mini」が1日制限つきで試せる

STEP 01ChatGPT / Gemini など

画像生成 — AIで「使える画像」を1枚作る

このステップでできるようになること

  • 文章（プロンプト）を打つだけで、SNS投稿やバナーに使える画像を作れる
  • 「思った通りの画像」に近づける指示の出し方が分かる

なぜ画像生成から始める？

AIの中でいちばん「結果が一瞬で目に見える」のが画像生成だから。コードも設定もいらず、チャットに文章を打つだけ。ここで「AIに指示を出す＝プロンプトを書く」感覚をつかんでおくと、このあとが全部ラクになります。ChatGPTでもGeminiでもOK、まずはどちらか1つで。

やってみよう

例として「AIセミナーの告知バナー」を作ります。チャット欄にこう打つ👇

プロンプト例
AIセミナーの告知用バナー画像を作って。
横長で、青を基調にした清潔感のあるデザイン。
ノートパソコンとグラフのイラストを入れて。
文字は入れなくていい。

返ってきた画像を見て、口語で修正していくのが本番👇

もう少し明るくして、もっとシンプルにしてほしい
左下に人物のシルエットを足して
全体をもう少しビジネスっぽく、落ち着いた雰囲気に

2〜3回くり返すとイメージに近づきます。気に入ったら保存。

つまづきポイント＆コツ

  • 「かっこいい画像作って」だけ → 抽象的すぎて毎回バラバラに

⭕ 4点セットで指定すると安定：①用途 ②雰囲気 ③入れる要素 ④色

文字は苦手画像内の日本語文字は崩れやすい。タイトル文字はあとからCanva等で乗せる前提が安全。無料プランは生成回数に上限あり。

完成イメージ／作例

  • Instagram投稿の表紙・告知バナー・ブログのアイキャッチ・アイコンのベース
STEP 02Gemini / Google Flow

動画生成 — AIで数秒のショート動画を1本作る

このステップでできるようになること

  • 文章を打つだけで、数秒のショート動画を作れる
  • SNSの背景動画や、商品・サービスの短い紹介クリップが自作できる

なぜ Gemini / Flow？

STEP①の静止画を「動かす」番。Googleの Veo という技術で文章から動画が作れます。手軽さ重視なら Gemini、動画を作り込みたいなら専用画面の Google Flow（無料枠あり）。まずはどちらか1つで。

やってみよう

例として「夕暮れの海辺を歩く後ろ姿」の8秒クリップを作ります。

プロンプト例（Gemini）
夕暮れの海辺を、後ろ姿で歩いている人の8秒の動画を作って。
シネマティックで、波の音が聞こえてきそうな雰囲気。
カメラはゆっくり後ろから追いかける感じで。

「もう少し明るい時間帯に」「カメラの動きをゆっくりに」など口語で修正 → 気に入ったらダウンロード。

つまづきポイント＆コツ

  • 無料枠の制限：8秒・720p・「Made with Veo」の透かし入り。Flowは1日のクレジット上限あり
  • 動きは"ひとつ"に絞る：「歩く」など動作を1つにすると安定。盛り込みすぎると崩れる
  • 長尺は苦手 → まず数秒の1カットで成功体験を。文字テロップは編集アプリで後乗せが安全

完成イメージ／作例

  • リール／TikTokの背景クリップ・商品紹介動画・告知のオープニング数秒
STEP 03ChatGPT / Gemini など

スライド作成 — 提案／自己紹介スライドを1セット作る

このステップでできるようになること

  • 「テーマ」を伝えるだけで、スライドの構成と文章をAIに作ってもらえる
  • 自己紹介・サービス提案・セミナー資料のたたき台が一瞬で用意できる

なぜ ChatGPT / Gemini？

スライドで時間がかかるのは「構成」と「各ページの文章」。ここをAIに任せると一気にラクに。構成→中身の順で作るのがコツです。

やってみよう

例として「SNS運用サービスの提案スライド」。まず構成（目次）から👇

プロンプト例①（構成）
SNS運用代行サービスの提案スライドを作りたい。
相手は美容サロンのオーナー。全8枚くらいで、
表紙→課題→解決策→事例→料金→次のステップ、の流れで
スライドの構成（各ページのタイトルと内容の要点）を作って。

構成にOKを出したら、1枚ずつ中身を作らせる👇

プロンプト例②（中身）
3枚目「解決策」のページの本文を、箇条書き3つで作って。
1行は短く、専門用語は使わないで。

出てきた文章を Googleスライド や Canva に貼って整えれば完成。

つまづきポイント＆コツ

  • AIは文字を詰め込みすぎる：「1スライド＝メッセージ1つ」「1行は短く」と指示して削る
  • 相手を必ず伝える：「誰に向けた資料か」を書くと刺さる言葉で書いてくれる
  • デザインはAIに求めすぎず、清書ツール側で。AIには「中身」を任せる
STEP 04Codex（メイン）/ Claude Code

スキル作成 — 自分の作業をAIに覚えさせる

「スキル」ってなに？

毎回ゼロから指示せず、「この作業はいつもこうやる」という手順をAIに登録しておくこと。一度作れば「あれやって」の一言で同じ品質の作業が返ってきます。例：議事録の整形、todoの優先度づけ、SNS投稿文のテンプレ化。ここからは作業のやり方そのものをAIに持たせる段階です。

Codexは無料ChatGPTプランでも「Codex Mini」が1日制限つきで試せます。まず無料で触ってみるのに最適。

やってみよう（Codexメイン）

例として「メモを決まった形式の議事録に整える」スキル。まず手順を言葉にする👇

プロンプト例
打ち合わせのメモを渡すので、いつも同じフォーマットの議事録に
整えるスキルを作りたい。フォーマットは
「日時／参加者／決まったこと／次のアクション」の4項目。
この作業をいつでも呼び出せるようにしたい。

Codexが手順・テンプレを提案 → 保存。次からはメモを貼って「議事録にして」と言うだけ。ズレたら一言で微調整して育てます。

💡 Claude Code でやる場合

Claude Codeには Skills という仕組みがあり、手順を1つのスキルとして保存 → /スキル名 で呼び出せます。やり方の核は同じ（言葉にする→保存→呼び出して育てる）。まず無料で触るなら Codex、保存・呼び出しをしっかり使うなら Claude Code。

つまづきポイント＆コツ

  • いきなり大きな自動化を狙わない。「1作業＝1スキル」で小さく
  • "やり方"を言葉にするのが9割。人に教えるつもりで書き出す
  • 一発で完成しない前提。使いながら「ここ直して」で育てる
STEP 05Codex（メイン）/ Claude Code

ツール作成 — ブラウザで動く小さなツールを1個作る

最後はなぜ「ツール作成」？

ここまでの成果物・スキルに続いて、最後は「人に使ってもらえるもの」を作ります。今はHTMLファイル1枚で動く小さなツールなら、コードを書けなくても「○○なツールを作って」と頼むだけで形になります。

Codexは無料の「Codex Mini」から試せます。まず無料で1個作ってみましょう。

やってみよう（Codexメイン）

例として「SNS投稿の文字数カウンター」。ポイントは「HTML1ファイルで」と添えること👇

プロンプト例
SNS投稿用の文字数カウンターを、HTML1ファイルで作って。
・テキストを入力すると、今の文字数がリアルタイムで表示される
・280文字を超えたら赤字で警告
・スマホでも見やすいシンプルなデザイン
コードを全部まとめて1つのファイルにして。

出てきたコードを counter.html で保存 → ダブルクリックでブラウザが開き、動きます。「色を青に」「コピーボタンを足して」など使いながら改良。

💡 Claude Code でやる場合

Claude Codeは、ファイルの作成・保存・動作確認まで自分でやってくれます。「○○なツールを作って」→ 作って確認まで。その場で「ここ直して」で書き換えてくれます。まず無料で1個なら Codex、保存や確認まで任せたいなら Claude Code。

つまづきポイント＆コツ

  • 「HTML1ファイルで」と頼む：1ファイル完結が初心者には扱いやすい
  • 1機能から。エラーはそのまま貼ればAIが直してくれる。完璧を求めず「動いた！」を大事に

おめでとう！5ステップ完走 🎉

① 画像 → ② 動画 → ③ スライド（AIに作ってもらう）
④ スキル → ⑤ ツール（自分用の仕組みを作る）

「AIに指示を出す」「AIに作業を任せる」「AIと一緒に作る」がひと通り体験できたはず。あとはこの5つを自分の仕事に組み合わせるだけ。

気になったステップに戻って、自分の業務に置き換えて作り直そう。
