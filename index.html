AI STEP-UP — 5つの実践ステップ

AI活用実践 5ステップマニュアル

手を動かしながら、AIを"使える"ようになる。
各ステップで必ず「自分の手で1個作る」実践教材です。

目次 はじめに ① 画像生成 ② 動画生成 ③ スライド作成 ④ スキル作成 ⑤ ツール作成

5段階でステップアップ

①→⑤の順に、だんだんできることが広がっていく構成です。①〜③はAIに「作ってもらう」体験、④〜⑤は自分用の「仕組みを作る」体験。気になるステップから読んでもOK。

STEPテーマ使うAI作るもの
①画像生成ChatGPT / Gemini などSNS投稿用の画像を1枚
②動画生成Gemini / Google Flow数秒のショート動画を1本
③スライド作成ChatGPT / Gemini など提案・自己紹介スライドを1セット
④スキル作成Codex / Claude Code作業を自動化するスキルを1個
⑤ツール作成Codex / Claude Codeブラウザで動くツールを1個

無料でも試せます（2026年時点）

有料版のAIを使った方が生成物のクオリティは高いですが、まずは無料版でも十分にこの5段階を体験できます。

ChatGPT / Gemini … 無料プランでOK（画像・動画生成は回数制限あり）／ Google Flow … 無料枠あり（非課金でも1日50クレジット・Veo 2／Lite中心）／ Codex … 期間限定で無料ChatGPTプランにも開放中。軽量版「Codex Mini」が1日制限つきで試せる

STEP 01ChatGPT / Gemini など

画像生成 — AIで「使える画像」を1枚作る

このステップでできるようになること

  • 文章（プロンプト）を打つだけで、SNS投稿やバナーに使える画像を作れる
  • 「思った通りの画像」に近づける指示の出し方が分かる

なぜ画像生成から始める？

AIの中でいちばん「結果が一瞬で目に見える」のが画像生成だから。コードも設定もいらず、チャットに文章を打つだけ。ここで「AIに指示を出す＝プロンプトを書く」感覚をつかんでおくと、このあとが全部ラクになります。

🎨 このステップで使うAI
ChatGPT か Gemini、まずはどちらか1つでOK。下のボタンから開けます。
ChatGPTを開く Geminiを開く

やってみよう｜プロンプト例5つ

下のプロンプトをコピーして貼り付け、出てきた画像を「もう少し明るく」「文字を消して」など口語で修正していくのが本番です。

① セミナー告知バナー
AIセミナーの告知用バナー画像を作って。
横長で、青を基調にした清潔感のあるデザイン。
ノートパソコンとグラフのイラストを入れて。
文字は入れなくていい。
② Instagram投稿の表紙
Instagram投稿の表紙に使う背景画像を作って。
正方形、パステル調でやわらかい雰囲気。
右下に小さく観葉植物。
あとで文字を乗せるので、中央は余白を広めにして。
③ ブログ／noteのアイキャッチ
ブログ記事のアイキャッチ画像を作って。
テーマは「副業の始め方」。
横長で、明るくポジティブな印象。
人物は入れず、コインと矢印のシンプルなイラストで。
④ プロフィールアイコンのベース
SNSのプロフィールアイコンに使うイラストを作って。
正方形、フラットでシンプルなデザイン。
コーヒーカップをモチーフに、背景は淡いベージュ1色。
⑤ 商品紹介の背景画像
化粧品の商品紹介に使う背景画像を作って。
高級感のある白〜ベージュのグラデーション。
中央に商品を置けるよう、まわりに余白と柔らかい影。
小物として花びらを少しだけ散らして。

つまづきポイント＆コツ

  • 「かっこいい画像作って」だけ → 抽象的すぎて毎回バラバラに

⭕ 4点セットで指定すると安定：①用途 ②雰囲気 ③入れる要素 ④色

文字は苦手無料版のAIだと画像内の日本語文字は崩れやすい。生成画像への日本語文字の出力を安定させるには有料版を活用するのが推奨です。また無料プランは生成回数の上限が少なめです。
STEP 02Gemini / Google Flow

動画生成 — AIで数秒のショート動画を1本作る

このステップでできるようになること

  • 文章を打つだけで、数秒のショート動画を作れる
  • SNSの背景動画や、商品・サービスの短い紹介クリップが自作できる

なぜ Gemini / Flow？

STEP①の静止画を「動かす」番。Googleの Veo という技術で文章から動画が作れます。手軽さ重視なら Gemini、動画を作り込みたいなら専用画面の Google Flow。

🎬 このステップで使うAI
まずは手軽な Gemini で1本。慣れたら動画専用の Google Flow（無料枠：1日50クレジット）へ。
Geminiを開く Google Flowを開く

やってみよう｜プロンプト例5つ

「もう少し明るい時間帯に」「カメラの動きをゆっくりに」など、出てきた動画を口語で修正していきます。

① 夕暮れの海辺（後ろ姿）
夕暮れの海辺を、後ろ姿で歩いている人の8秒の動画を作って。
シネマティックで、波の音が聞こえてきそうな雰囲気。
カメラはゆっくり後ろから追いかける感じで。
② コーヒーを淹れる手元
コーヒーをドリップしている手元のアップを8秒の動画で作って。
湯気がふわっと立ちのぼる、あたたかい朝の雰囲気。
カメラは固定で、ゆっくりとした動き。
③ 商品をくるっと見せる
白い背景の上で、化粧品のボトルがゆっくり360度回転する8秒の動画。
清潔感があって高級感のあるライティング。
余計な物は置かず、商品だけを引き立てて。
④ 都会の夜景（タイムラプス風）
都会の夜景を見下ろす8秒の動画。
車のライトが流れるタイムラプス風で、上品でスタイリッシュ。
SNSの背景クリップに使える雰囲気で。
⑤ 観葉植物に光が差す癒し系
窓辺の観葉植物に、朝の光がやわらかく差し込む8秒の動画。
ゆっくり葉が揺れる、癒し系でナチュラルな雰囲気。
カメラはほんの少しだけ寄っていく動き。

つまづきポイント＆コツ

  • 無料枠の制限：8秒・720p・「Made with Veo」の透かし入り。Flowは1日のクレジット上限あり
  • 動きは"ひとつ"に絞る：「歩く」など動作を1つにすると安定。盛り込みすぎると崩れる
  • 長尺は苦手 → まず数秒の1カットで成功体験を。文字テロップは編集アプリで後乗せが安全
STEP 03ChatGPT / Gemini など

スライド作成 — 提案／自己紹介スライドを1セット作る

このステップでできるようになること

  • 「テーマ」を伝えるだけで、スライドの構成と文章をAIに作ってもらえる
  • 自己紹介・サービス提案・セミナー資料のたたき台が一瞬で用意できる

なぜ ChatGPT / Gemini？

スライドで時間がかかるのは「構成」と「各ページの文章」。ここをAIに任せると一気にラクに。構成→中身の順で作るのがコツです。

📊 このステップで使うAI
構成と文章はChatGPT/Geminiで作り、見た目はGoogleスライドやCanvaで整えます。
ChatGPTを開く Geminiを開く

やってみよう｜プロンプト例5つ

むずかしく考えず、上から順にコピペして試すだけでOK。①で全体の骨組みを作って、②以降で1ページずつ仕上げていきます。

① まず構成を考えてもらう
自己紹介のスライドを作りたいです。
全部で5枚くらいで、各ページのタイトルだけ考えてください。
② 1ページぶんの文章を作る
1枚目「自己紹介」のページに書く文章を、
3行くらいの短い文で作ってください。
③ やさしい言葉に直す
次の文章を、スライド用に短く・やさしい言葉に直してください。

（ここに直したい文章を貼る）
④ 箇条書きにまとめる
次の内容を、スライドに載せる箇条書き3つにまとめてください。

（ここにまとめたい内容を貼る）
⑤ タイトル案を出してもらう
「はじめてのAI活用」というテーマのスライドの、
表紙タイトル案を5つ考えてください。

つまづきポイント＆コツ

  • AIは文字を詰め込みすぎる：「1スライド＝メッセージ1つ」「1行は短く」と指示して削る
  • 相手を必ず伝える：「誰に向けた資料か」を書くと刺さる言葉で書いてくれる
  • デザインはAIに求めすぎず、清書ツール側で。AIには「中身」を任せる
STEP 04Codex（メイン）/ Claude Code

スキル作成 — 自分の作業をAIに覚えさせる

「スキル」ってなに？

毎回ゼロから指示せず、「この作業はいつもこうやる」という手順をAIに登録しておくこと。一度作れば「あれやって」の一言で同じ品質の作業が返ってきます。ここからは作業のやり方そのものをAIに持たせる段階です。

Codexは期間限定で無料ChatGPTプランにも開放中。軽量版「Codex Mini」が1日制限つきで試せます（ChatGPTアカウントでサインイン。macOSのCodexアプリでも同じアカウントで使えます）。まず無料で触ってみるのに最適。

🛠 このステップで使うAI
まず無料で触るなら Codex。保存・呼び出しの仕組みをしっかり使うなら Claude Code。
Codexダウンロードはこちら Claude Codeダウンロードはこちら

「ChatGPT Codex」導入マニュアル→ デスクトップ版「Claude Code」画面の使い方→ Claude CodeのSkills機能で作業を半自動化する方法→ Claude Code解説動画【YouTube】→

やってみよう｜プロンプト例5つ

まず「やり方」を言葉にして渡し、スキルとして保存 → 次からは一言で呼び出します。

① 議事録フォーマット整形
打ち合わせのメモを渡すので、いつも同じフォーマットの議事録に
整えるスキルを作りたい。フォーマットは
「日時／参加者／決まったこと／次のアクション」の4項目。
この作業をいつでも呼び出せるようにして。
② todoの優先度づけ
やることを箇条書きで渡すので、
「緊急度×重要度」で並べ替えて、今日やるべき3つを選んでくれる
スキルを作って。理由も一言ずつ添えて。
③ SNS投稿文のテンプレ化
商品名と特徴を渡すと、Instagram投稿文を作るスキルを作りたい。
構成は「共感の一言→ベネフィット3つ→行動の呼びかけ→ハッシュタグ5個」。
親しみやすい口調で。
④ 問い合わせ返信の下書き
お客様からの問い合わせ文を貼ると、
ていねいな返信の下書きを作るスキルを作って。
「お礼→回答→次のご案内→締めの挨拶」の流れで、
かたすぎない敬語で。
⑤ 日報フォーマット
その日やったことを箇条書きで渡すと、
「今日の成果／気づき／明日やること」の3項目に整理した
日報にしてくれるスキルを作って。

つまづきポイント＆コツ

  • いきなり大きな自動化を狙わない。「1作業＝1スキル」で小さく
  • "やり方"を言葉にするのが9割。人に教えるつもりで書き出す
  • 一発で完成しない前提。使いながら「ここ直して」で育てる
STEP 05Codex（メイン）/ Claude Code

ツール作成 — ブラウザで動く小さなツールを1個作る

最後はなぜ「ツール作成」？

ここまでの成果物・スキルに続いて、最後は「人に使ってもらえるもの」を作ります。今はHTMLファイル1枚で動く小さなツールなら、コードを書けなくても「○○なツールを作って」と頼むだけで形になります。

Codexは期間限定で無料の「Codex Mini」から試せます。まず無料で1個作ってみましょう。

⚙️ このステップで使うAI
まず無料で1個作るなら Codex。保存や動作確認まで任せたいなら Claude Code。
Codexダウンロードはこちら Claude Codeダウンロードはこちら
📘 この導入ガイドを閲覧しよう👇️
「ChatGPT Codex」導入マニュアル→ デスクトップ版「Claude Code」画面の使い方→ Claude Codeにブラウザ操作をさせる拡張機能→ Claude Code解説動画【YouTube】→

やってみよう｜プロンプト例5つ

ポイントは「HTML1ファイルで作って」と添えること。1ファイル完結だと保存して開くだけで動きます。

① 文字数カウンター
SNS投稿用の文字数カウンターを、HTML1ファイルで作って。
・テキストを入力すると、今の文字数がリアルタイムで表示される
・280文字を超えたら赤字で警告
・スマホでも見やすいシンプルなデザイン
コードを全部まとめて1つのファイルにして。
② ハッシュタグ生成ツール
キーワードを入れるとハッシュタグ候補を出すツールを、HTML1ファイルで作って。
・キーワードを入力して「生成」を押すと、関連ハッシュタグを10個表示
・各タグにコピーボタン
・スマホ対応のシンプルなデザイン
③ 割り勘計算ツール
飲み会の割り勘計算ツールを、HTML1ファイルで作って。
・合計金額と人数を入力すると、1人あたりの金額を表示
・100円単位で切り上げる切り替えスイッチ付き
・大きく見やすい数字で表示
④ 簡易見積もりツール
SNS運用代行の簡易見積もりツールを、HTML1ファイルで作って。
・「投稿数」「動画編集の有無」などを選ぶと概算金額が出る
・最後に合計金額を大きく表示
・落ち着いた青基調のデザインで
⑤ チェックリスト／診断
「AI活用度チェック」の簡単な診断ツールを、HTML1ファイルで作って。
・5つの質問にはい/いいえで答える
・最後にスコアと一言コメントを表示
・スマホで使いやすいシンプルなデザイン

つまづきポイント＆コツ

  • 「HTML1ファイルで」と頼む：1ファイル完結が初心者には扱いやすい
  • 1機能から。エラーはそのまま貼ればAIが直してくれる。完璧を求めず「動いた！」を大事に

おめでとう！5ステップ完走 🎉

① 画像 → ② 動画 → ③ スライド（AIに作ってもらう）
④ スキル → ⑤ ツール（自分用の仕組みを作る）

「AIに指示を出す」「AIに作業を任せる」「AIと一緒に作る」がひと通り体験できたはず。あとはこの5つを自分の仕事に組み合わせるだけ。

気になったステップに戻って、自分の業務に置き換えて作り直そう。
