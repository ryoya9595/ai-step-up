AI STEP-UP — 5つの実践ステップ

手を動かしながら、
AIを"使える"ようになる

読むだけで終わらせない。各ステップで必ず「自分の手で1個作る」。
画像から始めて、最後は自分専用のツールを作るところまで。

5つのステップ

①→⑤の順に、だんだんステップアップしていく構成です。気になるステップから読んでもOK。

STEP 01

画像生成

ChatGPT / Gemini など

文章を打つだけで、SNS投稿に使える画像を1枚作る。

→ STEP 02

動画生成

Gemini / Google Flow

テキストから、数秒のショート動画を1本作る。

→ STEP 03

スライド作成

ChatGPT / Gemini など

テーマを伝えるだけで、提案・自己紹介スライドを1セット作る。

→ STEP 04

スキル作成

Codex / Claude Code

いつもの定型作業を、AIに「スキル」として覚えさせる。

→ STEP 05

ツール作成

Codex / Claude Code

頼むだけで、ブラウザで動く小さなツールを1個作る。
