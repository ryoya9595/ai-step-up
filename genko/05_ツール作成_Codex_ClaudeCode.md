# STEP⑤ ツール作成 — ブラウザで動く小さなツールを1個作る

> 使うAI：**Codex（メイン）/ Claude Code**
> Codexは無料ChatGPTプランでも **Codex Mini** が1日制限つきで試せる。

## このステップでできるようになること
- 自然な日本語で頼むだけで、ブラウザで動く小さなツールを作れるようになる
- 「あったら便利」を、人にも使ってもらえる形にできる

---

## 最後はなぜ「ツール作成」？
ここまでで、画像・動画・スライド（成果物）と、スキル（自分用の仕組み）を作ってきた。
最後は **「人に使ってもらえるもの」** を作る。これがAI活用のゴールのひとつ。

しかも今は、HTMLファイル1枚で動く小さなツールなら、
コードを書けなくても**「○○なツールを作って」と頼むだけ**で形になる。

例えばこんなツール👇
- SNS投稿の文字数カウンター
- ハッシュタグをまとめて生成するツール
- 割り勘・見積もりの簡易計算ツール
- 簡単な予約・問い合わせフォーム

---

## なぜ Codex（または Claude Code）？
スキル(STEP④)が「作業の自動化」なら、ツールは「動くプログラム」。
コードを書いて、ファイルにして、ブラウザで動かす——この一連を任せられるのが開発系AI。

- **Codex** … 「○○を作って」でコードを生成。無料の Codex Mini から試せる。
- **Claude Code** … ファイル作成・修正・プレビュー確認まで一気にやってくれる。

## やってみよう（手順）※Codexメイン

### 1. 作るツールを1つ決める
今回は例として **「SNS投稿の文字数カウンター」** を作る。

### 2. Codexに頼む
ポイントは「**HTML1ファイルで動くように**」と添えること。初心者が扱いやすい。

```
SNS投稿用の文字数カウンターを、HTML1ファイルで作って。
・テキストを入力すると、今の文字数がリアルタイムで表示される
・280文字を超えたら赤字で警告
・スマホでも見やすいシンプルなデザイン
コードを全部まとめて1つのファイルにして。
```

### 3. ファイルを保存してブラウザで開く
出てきたコードを `counter.html` などの名前で保存 →
ダブルクリックでブラウザが開き、ツールが動く。

### 4. 直していく
「色を青にして」「コピーボタンを足して」など、
**使いながら一言ずつ**改良していく。

---

### 💡 Claude Code でやる場合
Claude Codeは、ファイルの作成・保存・プレビュー確認まで自分でやってくれる。
- 「○○なツールを作って」と頼む → ファイルを作って動作確認までしてくれる
- その場で「ここ直して」と言えば、ファイルを直接書き換えてくれる

**どちらでもOK。** まず無料で1個作ってみたいなら Codex、保存や動作確認まで任せたいなら Claude Code。

---

## つまづきポイント＆コツ

- **「HTML1ファイルで」と頼む**：複数ファイルやインストールが必要なものは初心者には難しい。1ファイル完結が扱いやすい。
- **1機能から**：最初から多機能を狙わない。「文字数を数える」だけ作って、後から足す。
- **エラーはそのまま貼る**：動かなかったら、画面のエラー文をそのままAIに貼れば直してくれる。
- **完璧を求めない**：まず動くものを1個。「動いた！」の体験がいちばん大事。
