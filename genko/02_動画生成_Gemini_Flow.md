# STEP② 動画生成 — AIで数秒のショート動画を1本作る

> 使うAI：**Gemini / Google Flow**（どちらも無料枠あり／Googleアカウントだけで開始OK）
> このページではまず Gemini で解説。もっと"動画づくり"に特化したいなら Google Flow（後述）。

## このステップでできるようになること
- 文章を打つだけで、数秒のショート動画を作れるようになる
- SNSの背景動画や、商品・サービスの短い紹介クリップが自作できる

---

## なぜ動画生成を、Gemini / Flow で？
STEP①で「静止画」を作れた。次はそれを**動かす**番。
今は文章から数秒の動画が作れる時代で、Googleの **Veo** という技術がそれを支えている。

- **Gemini** … チャットで「〜な動画を作って」と打つだけ。いちばん手軽。
- **Google Flow** … Veoを使った"動画づくり専用"の画面。クリップをつなげたり調整できる。無料枠あり。

**まずはどちらか1つでOK。** 手軽さ重視ならGemini、動画を作り込みたくなったらFlow。

## やってみよう（手順）

### 1. お題を決める
今回は例として **「夕暮れの海辺を歩く後ろ姿」** の8秒クリップを作る。

### 2. プロンプトを打つ（Geminiの場合）
チャット欄にこう打つ👇

```
夕暮れの海辺を、後ろ姿で歩いている人の8秒の動画を作って。
シネマティックで、波の音が聞こえてきそうな雰囲気。
カメラはゆっくり後ろから追いかける感じで。
```

→ 少し待つと動画が生成される。

### 3. 修正する
イメージと違ったら、口語で直す。

```
もう少し明るい時間帯にして
```
```
カメラの動きをもっとゆっくりに
```

### 4. 保存する
気に入ったらダウンロード。SNSにそのまま投稿してもいいし、編集アプリで文字を乗せてもいい。

### （応用）Google Flow を使う場合
Flowは「シーンを並べて1本の動画にする」のが得意。
Geminiで1クリップ作れるようになったら、Flowで複数クリップをつなぐステップに進むと作品っぽくなる。

---

## つまづきポイント＆コツ

- **無料枠の制限を知っておく**：無料だと **8秒・720p・「Made with Veo」の透かし入り**。Flowは1日分のクレジット上限があり、使い切ると翌日まで待つ。
- **長い動画はまだ苦手**：まずは数秒の1カットで成功体験を。長尺は複数クリップをつなぐ発想で。
- **動きは"ひとつ"に絞る**：「歩く」「振り返る」「手を伸ばす」など動作を1つにすると安定する。盛り込みすぎると崩れる。
- **文字・ロゴは入れない前提**：動画内の文字は崩れやすい。テロップは編集アプリで後乗せが安全。
