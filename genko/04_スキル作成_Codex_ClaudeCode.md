# STEP④ スキル作成 — 自分の作業をAIに覚えさせる

> 使うAI：**Codex（メイン）/ Claude Code**
> Codexは無料ChatGPTプランでも **Codex Mini** が1日制限つきで試せる。

## このステップでできるようになること
- いつも手でやっている定型作業を、AIに「スキル」として覚えさせられる
- 次からは短い一言で、同じ作業を呼び出して自動でやってもらえる

---

## 「スキル」ってなに？
毎回ゼロから指示を打つのではなく、
**「この作業はいつもこうやる」という手順をAIに登録しておく**こと。
一度作れば、次からは「あれやって」の一言で同じ品質の作業が返ってくる。

例えばこんな作業👇
- 議事録のメモを、決まったフォーマットの議事録に整える
- 毎朝のtodoを優先度つきで並べ替える
- 商品名を渡すと、SNS投稿文のテンプレに当てはめる

STEP③までは「AIに作ってもらう」だった。ここからは**作業のやり方そのものをAIに持たせる**段階。

---

## なぜ Codex（または Claude Code）？
画像・動画・スライドは「1回ごとの成果物」。
スキル作成は「**繰り返し使う仕組み**」を作る作業なので、
文章だけでなくファイルや手順を覚えられる開発系AIが向いている。

- **Codex** … OpenAIの開発支援AI。無料でも Codex Mini で試せるのが入り口に最適。
- **Claude Code** … Anthropic製。"Skills" という形で手順を保存・再利用できる仕組みが強力。

---

## 事前準備
- [ ] Codex を使う場合：ChatGPTアカウントでサインイン →「Codex」を開く（無料はCodex Mini）
- [ ] Claude Code を使う場合：Claudeのデスクトップアプリ等を用意
- [ ] 「いつもやっている定型作業」を1つ書き出しておく（小さいものでOK）

---

## やってみよう（手順）※Codexメイン

### 1. 覚えさせたい作業を1つ決める
今回は例として **「メモ書きを、決まった形式の議事録に整える」** スキルを作る。

### 2. Codexに"やり方"を相談する
いきなり完成形を作らせず、まず手順を言葉にする。

```
打ち合わせのメモを渡すので、いつも同じフォーマットの議事録に
整えるスキルを作りたい。フォーマットは
「日時／参加者／決まったこと／次のアクション」の4項目。
この作業をいつでも呼び出せるようにしたい。
```

### 3. テンプレートとして保存する
Codexが手順・テンプレを提案してくれるので、それを保存。
次からは **メモを貼って「議事録にして」と言うだけ**で、同じ形に整う。

### 4. 試して、直す
実際にメモを渡してみて、出力がズレたら
「次アクションは箇条書きにして」など**一言で微調整**して育てていく。

---

### 💡 Claude Code でやる場合
Claude Codeには **Skills** という仕組みがあり、手順を1つのスキルとして保存できる。
- 「○○するスキルを作って」と相談 → スキルとして登録
- 次からは `/スキル名` のように呼び出して実行
- やり方の核は同じ（やり方を言葉にする → 保存 → 呼び出して育てる）

**どちらでもOK。** まず無料で触りたいなら Codex、保存・呼び出しの仕組みをしっかり使いたいなら Claude Code。

---

## つまづきポイント＆コツ

- **いきなり大きな自動化を狙わない**：まずは「1作業＝1スキル」。小さく作って成功体験を。
- **"やり方"を言葉にするのが9割**：自分が普段やっている手順を、人に教えるつもりで書き出すとうまくいく。
- **一発で完成しない前提**：使いながら「ここ直して」を重ねて育てる。最初から完璧を求めない。
- **無料枠の制限**：Codex Miniは1日の利用回数に上限あり。出なくなったら時間を置く。
