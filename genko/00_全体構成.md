# AIステップアップ教材 — 全体構成（たたき台）

## コンセプト
「AIを"使える"ようになるための5ステップ」を、初心者が順番にtryしていける実践教材。
読むだけで終わらせず、各ステップで必ず「自分の手で1個作る」ことをゴールにする。

## ターゲット
- AIを触ってみたいけど何から始めればいいか分からない初心者
- RISE受講生 / SNS運用を頑張りたい人
- 「とりあえず動くもの・使えるもの」を作って自信をつけたい層

## 5つのステップと使うAI

| STEP | テーマ | 使うAI | 作るもの（ゴール） |
|------|--------|--------|----------------------|
| ① | 画像生成 | ChatGPT / Gemini など | SNS投稿用の画像を1枚 |
| ② | 動画生成 | Gemini / Google Flow | 数秒のショート動画を1本 |
| ③ | スライド作成 | ChatGPT / Gemini など | 提案 or 自己紹介スライドを1セット |
| ④ | スキル作成 | Claude Code / Codex | 自分専用の作業を自動化するSkillを1個 |
| ⑤ | ツール作成 | Claude Code / Codex | ブラウザで動く小さなツールを1個 |

> **無料で試せる点（2026年時点）：**
> - **Google Flow（Step②）** … 無料枠あり。1日50クレジット（一部の国は180）が毎日リセット。出力は720p・8秒・透かし入り。Googleアカウントだけで開始可。
> - **Codex（Step④⑤）** … 無料ChatGPTプランでも **Codex Mini** が1日制限つきで使える。フル機能は有料だが、「まず触ってみる」なら無料で十分。

### 設計の意図
- **①→⑤でだんだんステップアップ**：最初はAIに指示して作ってもらう（画像・動画・スライド）、後半は自分用の仕組みを作る（スキル・ツール）。
- **難易度がなだらかに上がる**：いきなりコードに行かず、まず "プロンプトを書く" 体験から。
- **AIを使い分ける体験**：1つのAIに依存せず「目的でAIを選ぶ」感覚が身につく。

## 各ステップ共通フォーマット（型）
すべてのステップをこの構成で統一する：

1. **このステップでできるようになること**（1〜2行）
2. **使うAIと、なぜそれを選ぶか**
3. **事前準備**（アカウント・必要なもの）
4. **やってみよう（手順）** — 画面の流れに沿ってステップバイステップ
5. **つまづきポイント＆コツ**
6. **完成イメージ／作例**
7. **次のステップへ**（ひとことで橋渡し）

## サイト化の方針（後工程）
- 静的サイト（HTML/CSS、フレームワーク無しでもOK）
- トップページ＝5ステップの一覧（カード型）
- 各ステップ＝1ページ
- GitHub Pages で公開
- スマホでも読める前提（受講生はスマホ閲覧が多い想定）
