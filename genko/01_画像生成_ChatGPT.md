# STEP① 画像生成 — AIで「使える画像」を1枚作る

> 使うAI：**ChatGPT / Gemini など**（無料プランでもOK／画像生成は回数制限あり）
> このページではまず ChatGPT で手順を解説。Gemini でもほぼ同じ流れで作れる（後述）。

## このステップでできるようになること
- 文章（プロンプト）を打つだけで、SNS投稿やバナーに使える画像を作れるようになる
- 「思った通りの画像」に近づけるための指示の出し方が分かる

---

## なぜ画像生成から始める？
AIの中でいちばん「結果が一瞬で目に見える」のが画像生成だから。
コードも設定もいらない。チャットに文章を打つだけで絵が返ってくる。
ここで「AIに指示を出す＝プロンプトを書く」感覚を最初につかんでおくと、
このあとの動画・スライド・ツール作りが全部ラクになる。

### なぜChatGPT？
- 日本語の指示がそのまま通る（翻訳いらず）
- 「もうちょっと明るく」「文字を消して」みたいに**会話で修正できる**
- アカウントを1つ作れば、このあとのSTEP③スライドでも同じものを使える

### Geminiでもできる
同じことは Google の **Gemini** でも可能。やり方はほぼ同じで、チャット欄に
「〜な画像を作って」と打つだけ。Googleアカウントがあればすぐ使える。
**まずはどちらか1つでOK。** 慣れてきたら両方試して「出てくる絵の好み」で選ぶといい。

## 事前準備
- [ ] ChatGPTのアカウント（無料でOK）
  - https://chatgpt.com にアクセス → Googleアカウントなどで登録
- [ ] 「どんな画像が欲しいか」をざっくり1つ決めておく
  - 例：「自分のInstagram投稿用の表紙画像」「セミナー告知バナー」など

## やってみよう（手順）

### 1. お題を決める
まずは欲しい画像を1つに絞る。今回は例として
**「AIセミナーの告知バナー」** を作ってみる。

### 2. 最初のプロンプトを打つ
ChatGPTのチャット欄に、こう打ち込む👇

```
AIセミナーの告知用バナー画像を作って。
横長で、青を基調にした清潔感のあるデザイン。
ノートパソコンとグラフのイラストを入れて。
文字は入れなくていい。
```

→ 数十秒で画像が返ってくる。

### 3. 会話で修正していく（ここが本番）
一発で完璧は出ない。返ってきた画像を見て、**口語で直す**。

```
もう少し明るくして、もっとシンプルにしてほしい
```
```
左下に人物のシルエットを足して
```
```
全体をもう少しビジネスっぽく、落ち着いた雰囲気に
```

これを2〜3回くり返すと、ぐっとイメージに近づく。

### 4. 保存する
気に入った画像が出たら、画像を右クリック（スマホは長押し）→ 保存。

---

## つまづきポイント＆コツ

- **❌「かっこいい画像作って」だけ** → 抽象的すぎて毎回バラバラなものが出る
- **⭕ 4点セットで指定すると安定する：**
  1. **用途**（何に使う？例：Instagram投稿／バナー／アイコン）
  2. **雰囲気**（清潔感／かわいい／高級感 など）
  3. **入れる要素**（人物・小物・背景）
  4. **色**（青基調／パステル など）
- **文字は苦手**：画像内の日本語文字は崩れやすい。タイトル文字はあとからCanva等で乗せる前提が安全。
- **回数制限に注意**：無料プランは時間あたりの生成回数に上限あり。出なくなったら少し時間を置く。

## 完成イメージ／作例
- Instagram投稿の表紙画像
- セミナー・イベントの告知バナー
- ブログ／noteのアイキャッチ
- プロフィールアイコンのベース

「文字なしの背景・素材」をAIで作って、文字入れだけ別ツールでやると失敗が少ない。
