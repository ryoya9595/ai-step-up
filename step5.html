STEP 05 Codex（メイン）/ Claude Code

ツール作成 — ブラウザで動く小さなツールを1個作る

Codexは無料ChatGPTプランでも「Codex Mini」が1日制限つきで試せます。まず無料で1個作ってみましょう。

最後はなぜ「ツール作成」？

ここまでで、画像・動画・スライド（成果物）と、スキル（自分用の仕組み）を作ってきた。最後は 「人に使ってもらえるもの」 を作ります。これがAI活用のゴールのひとつ。

しかも今は、HTMLファイル1枚で動く小さなツールなら、コードを書けなくても「○○なツールを作って」と頼むだけで形になります。

例えばこんなツール👇

  • SNS投稿の文字数カウンター
  • ハッシュタグをまとめて生成するツール
  • 割り勘・見積もりの簡易計算ツール
  • 簡単な予約・問い合わせフォーム

なぜ Codex（または Claude Code）？

スキル(STEP④)が「作業の自動化」なら、ツールは「動くプログラム」。コードを書いて、ファイルにして、ブラウザで動かす——この一連を任せられるのが開発系AIです。

  • Codex … 「○○を作って」でコードを生成。無料の Codex Mini から試せる。
  • Claude Code … ファイル作成・修正・プレビュー確認まで一気にやってくれる。

事前準備

  • Codex（無料はCodex Mini）または Claude Code
  • 「どんなツールが欲しいか」を1つ決める（小さくてOK）
  • できたファイルを保存する場所(デスクトップでOK)

やってみよう（手順）※Codexメイン

1. 作るツールを1つ決める

今回は例として 「SNS投稿の文字数カウンター」 を作ります。

2. Codexに頼む

ポイントは「HTML1ファイルで動くように」と添えること。初心者が扱いやすい。

SNS投稿用の文字数カウンターを、HTML1ファイルで作って。
・テキストを入力すると、今の文字数がリアルタイムで表示される
・280文字を超えたら赤字で警告
・スマホでも見やすいシンプルなデザイン
コードを全部まとめて1つのファイルにして。

3. ファイルを保存してブラウザで開く

出てきたコードを counter.html などの名前で保存 → ダブルクリックでブラウザが開き、ツールが動きます。

4. 直していく

「色を青にして」「コピーボタンを足して」など、使いながら一言ずつ改良していきます。

💡 Claude Code でやる場合

Claude Codeは、ファイルの作成・保存・プレビュー確認まで自分でやってくれます。

  • 「○○なツールを作って」と頼む → ファイルを作って動作確認までしてくれる
  • その場で「ここ直して」と言えば、ファイルを直接書き換えてくれる

どちらでもOK。まず無料で1個作ってみたいなら Codex、保存や動作確認まで任せたいなら Claude Code。

つまづきポイント＆コツ

  • 「HTML1ファイルで」と頼む： 複数ファイルやインストールが必要なものは初心者には難しい。1ファイル完結が扱いやすい
  • 1機能から： 最初から多機能を狙わない。「文字数を数える」だけ作って、後から足す
  • エラーはそのまま貼る： 動かなかったら、画面のエラー文をそのままAIに貼れば直してくれる
  • 完璧を求めない： まず動くものを1個。「動いた！」の体験がいちばん大事

完成イメージ／作例

  • 文字数カウンター／ハッシュタグ生成ツール
  • 割り勘・見積もり計算ツール
  • 簡単な診断・チェックリストツール
  • お問い合わせフォームの雛形

おめでとう！5ステップ完走 🎉

① 画像 → ② 動画 → ③ スライド（AIに作ってもらう）
④ スキル → ⑤ ツール（自分用の仕組みを作る）

ここまでで「AIに指示を出す」「AIに作業を任せる」「AIと一緒に作る」がひと通り体験できたはず。あとはこの5つを自分の仕事に組み合わせるだけ。気になったステップに戻って、自分の業務に置き換えて作り直してみよう。
